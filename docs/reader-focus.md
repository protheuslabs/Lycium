# Lesson Reader And Focus Mode

The global site header appears on Home, Catalog, My Learning, Tools, Studio, and
course overview pages. Entering an actual lesson replaces it with a compact
course toolbar.

The normal lesson toolbar contains:

- A course-overview exit with course identity.
- The existing collapsible outline and mobile drawer.
- Current section position and authorized editing controls.
- A focus-mode toggle.

Focus Mode hides the outline, position, and editing controls while preserving
the lesson, its source/context notices, previous/next/completion navigation, a
small course-overview exit, and Exit focus mode. Escape also exits Focus Mode.
The mode does not alter course progress, bookmarks, assessment attempts, or
storage.

The reader is intentionally distinct from discovery, but it must not trap the
learner or hide assessment rules. The global header remains on the overview so
learners can evaluate a course before entering the focused workspace.
